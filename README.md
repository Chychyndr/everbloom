# Flower

A procedural gallery of animated ASCII flowers on a black background.

## Features

- Ten flower compositions rendered with projected 3D particles.
- Animated growth, rotation, pollen and particle transitions.
- Automatic cycling every 24 seconds; click or tap to skip.
- Pointer parallax, responsive layout and reduced-motion support.
- No external assets or dependencies.

## Run locally

Open `index.html` in a modern browser.

## Deployment

Deploy the root directory using GitHub Pages. No build step is required.

## Stack

HTML, CSS, JavaScript, and Canvas 2D.
